# 第8节（2026-11-23）教师开课前必读｜v12.4.6 候选版

> 本包尚未在你真实的腾讯云/EdgeOne/第三方服务器环境实测，也**没有自动部署**，不能保证服务器的数据库、图片存储和 Coze 凭据已正确配置。发布前须使用原服务器及原环境变量，切勿用本地空库替换线上数据。

## 一、学生的真实任务

1. **完成原型**：继续制作辅助绘画装置，用一张真实作品整体照片展示目前状态。尚未完成可以先保存，不能为了发布把未完成说成已完成。
2. **五步设计简介 + 体会**：短句填写共情、定义、构思、原型、测试、体会。未做用户测试就如实写“尚未测试”，绝不编造观察结果。
3. **发布作品**：点击第1步“发布作品，进入全班互评”。只有发布之后才进入作品墙，只有已发布作品才公开给同学。
4. **同伴互评**：作品墙展示编号、作品整体照、六条简介。学生对其他两份已发布作品填写“具体优点 / 需要核实的问题 / 可操作建议”，不能评自己的作品。若当时可评价作品不足两份，则按实际已发布数量检查，避免先完成的同学被卡住。
5. **AI求助与决策**：每人本节至少完成一轮真实的学生提问+AI回复，可以围绕制作卡点、同伴建议、材料条件或验证方案，不设多轮凑数。学生自己决定如何处理同伴与AI建议；实验条件之间不改变统一的互评要求。
6. **课后回顾**：原已有的两种条件的回顾方式保持，实验条件选本节真实AI回复、写有无帮助及下次求助方法；普通条件记录真实进度。没有平台可用对话时如实说明，遇网络故障请教师协助，不编造聊天。

- 在本地运行 `npm test` / `npm run build`，服务器上线后再次检查健康版本 `course-v12.4.6-lesson8-evidence` 与三页 JS 缓存已刷新。

## 六、v12.4.6 本轮新增（2026-11-23）

- **两组共同的简短记录**：第8节互评页追加四项选填字段：本节实际修改、修改原因、是否参考 AI、如何处理 AI 建议。A/B 都看到同一表格；允许“尚未修改”“未参考AI”，不能据选择直接判断作品真的变化。按现有 `/session/save` 保存到 W8 的 `text_fields`，不改变 Blob 路径，也不影响已有记录。
- **当轮原始请求留痕**：保持“学生消息先写入，AI 再回复”的机制；新消息增加 `request_capture_stage`、`preceding_assistant_message_id`、`preceding_ai_scaffold_type`、`preceding_ai_route` 等可选字段，供后期区分当轮提示前的原始请求与后续反馈上下文；不采集未发送正文。既有历史消息没有这些字段属于正常情况。
- 教师 CSV/ZIP 聊天导出同步添加上述字段；**不能仅凭 previous_scaffold 就断定下一条一定是同一求助事件的修订稿**，研究时须人工结合文本和时间线编码。
- 课堂 **12节正式课 + 第13节全校展示**；旧 W14/W15 命名仅保留作历史 Blob/配置兼容，不代表有第14—16节教学。
- 预先制作的前测问卷功能仍默认关闭；今天绝不补写成“第2节已经发放”。如果要核实历史基线，请从真实第2节日志和作品/真实施测题本入手。
- Coze 四路 V2 只保留 `off/test/on` 的接口兼容，默认 `off`。ZIP 不会自动创建或发布 Coze 云端工作流。
