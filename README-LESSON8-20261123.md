# 第8节（2026-11-23）三步迭代与班级互评 — v12.5.1

## 学生页面只做三件事

1. **上传图纸和作品图**。上传当前真实成果，各一张。
   - 已有完整版本而**不需要修改**：点「提交当前版本，填写五步设计过程」。
   - **需要修改**：点「继续迭代，上传下一版」，简短写本版变化，再上传两张新版照片；旧版完整保留。
   - **没做完**：点「保存进度并退出」。已经上传的图纸和作品图不会丢失；未完成、不测试都可如实记录。
2. **填写五步设计过程并发布**。简短填写共情、定义、构思、原型、测试，然后点「上传并发布到作品墙，去互评」。上传的是已保存的最新作品图与填写的五步过程，无需重复选照片。提交第一步后才出现五步表单。
3. **评价其他同学的作品**。每人评价至少两份（实际可用不足两份时按可用数）；记录处理建议和必要修改；完成本节提交。

**AI 始终可用**：上传/迭代、五步描述、同伴互评均可向 AI 提问。A 组为普通 AI，B 组为原有学业求助支架，不改变人设及消息存储。
**最终提交**累计至少 **3 轮有效 AI 问答**（学生发消息并收到 AI 答复），前两个步骤不强制轮次。
