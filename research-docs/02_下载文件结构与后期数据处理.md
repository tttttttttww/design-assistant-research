# v11.48研究数据下载与拼接说明

## 最关键的下载按钮

教师后台 → **行为统计/人工编码** → 选择对应课次（如W5）：

1. **下载该课统计CSV**：`helpseeking_participant_session_measures.csv`（S01–S30每人一行，未对话的人也保留，IHS/EHS比例留空而非0）。
2. **下载该课逐条编码CSV**：`human_coding_with_source_messages.csv`（源句子 + IHS/EHS/OTHER/NOT_HELP + D/H/E/P + 主过程）。
3. **下载该课过程序列CSV**：`human_coded_process_sequence.csv`（只有已有明确人工标签的事件；未编码不能自动补齐）。
4. **下载该课全部作品版本CSV**：`artifact_versions_and_ai_links.csv`（版本、图片Blob路径、时间、修改原因、学生自述、链接AI回复、研究者核实）。
5. **下载该课轻量研究表ZIP（无图）**：`research_tables_W5.zip` 等，包括上述主要表、全部角色AI聊天、行动轨迹和文字修订历史，适合避免图片太多导致超时。
6. **逐课历史原始备份ZIP**：`original_history_W1.zip` / `W2` / `W3` … 包含本课所有原始存储对象和图片文件。**只有这个或作品图片ZIP才真正含原图**。
7. **任务记录+作品ZIP**：`task_records_and_works.zip` 中按S01/W5/图片类型/版本号存每次上传原图，包括误传更正之前的图和能找到的旧版未索引图片，并附对应路径CSV。

所有导出使用匿名编号，**不把学生明文姓名输出**。学生隐私数据应只保存到受控研究空间。

## 文件之间如何匹配

- 参与者：`participant_id`（如S01）；课次：`session_id` 或 `course_session_id`（如W5）；求助消息：`message_index`/`message_id`。
- AI回复：`message_id`；作品关联：`linked_ai_message_id` → 完整聊天中的`message_id`，不应只按文本相似匹配。
- 上传版本：`version_id`；同课次前一版本：`previous_version_id`；上一课图纸：`based_on_previous_session_version_ref`，形如`W4:xxxx`。
- 时间：`uploaded_at`, `created_at`，按带时区ISO字符串或解析后的时间戳处理。旧版恢复但原上传时间未知的图片设空并标`original_order_unknown`，不可强行排序解释。
- AI反馈真实帮助利用：只有当`researcher_link_verification=evidence_supported`且`researcher_change_nature=substantive`时，进入有核实证据子集；若是`correction`必须排除。
- 行动轨迹：`event_index/type/at`仅提供操作事实；`ai_draft_deleted_unsent`并不等于回避求助。

## 下载失败如何排查

1. 先点后台的**下载小CSV测试**并检查磁盘下载目录是否有 `download_test.csv`，然后点**当课统计CSV**；再点**当课轻量研究表ZIP**；最后尝试含图片的逐课原始ZIP。
2. 如果CSV正常但图片ZIP失败，优先改为单人单课完整ZIP；检查服务器日志和EdgeOne执行时间限制，并核对图片在Blob中是否存在。
3. 使用可信的HTTPS域名和登录态；Chrome下载列表内检查文件是否实际落地，浏览器收到保存请求不保证磁盘保存成功。
4. 检查文件前几个字节：CSV应该是文本（本项目UTF-8 BOM）；ZIP应该以`PK`开头。无法解压表示实际下载未完成，不能作为数据备份。
5. `history-session/...zip`中的`MANIFEST.json`列出当次扫描到的对象数、大小与未读取到的对象列表。确认非空、人数/对象数与课堂记录匹配后再算“备份成功”。
6. 更新代码时**不要**变更`EXPERIMENT_RUN_ID`、`BLOB_STORE_NAME`，也不要新建空Blob库；不要运行任何清空脚本。切换课次不等于删旧数据。

**验收最低标准**：使用S00/S99模拟在W5上传初稿、修改1、修改2和误传更正；后台查看4张图；下载轻量ZIP并确认CSV完整；下载含图片的W5原始ZIP并解压，核对4张图片哈希；最后核查W1—W4仍存在且文件能下载。只有线上实际验收成功，才能确认部署可用。
