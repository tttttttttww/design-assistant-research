# v12.4.8 今天下午操作说明（求助练习改进＋授权录屏）

**适用：2026-11-23，第8节，原型展示、五步简介、班级作品墙、互评和AI讨论。**

## 当前包含的功能

- 固定 S01—S30 学生身份，S00 支架测试与 S99 普通条件测试；保留教师后台和既有 A/B 条件映射（禁止重新分组）。
- 原型整体图上传、共情/定义/构思/原型/测试五步简介、一句话体会、发布到匿名班级作品墙；只显示发布过的编号和公开内容。
- 不能评价自己；同学对已发布作品给出优点、需要核查的问题及可操作建议；作品不足两份时按实际可评价数处理。
- 第8节至少三轮真实的学生—AI完整问答（两组相同；该要求是课堂任务约束，研究分析需要标注非完全自发）。
- 两组相同的**选填**记录：实际修改、修改原因、是否参考 AI、AI 建议如何处理。
- B组保留已有求助教学与历史回顾规则，A组保持普通AI；新的 Coze 四路V2工作流默认关闭且没有自动上线。
- 学生请求先存原文，再调用 AI；保存当轮提示前请求及上一条AI反馈的上下文关联字段，未发送草稿文本不会收集。
- 原有 W7 图纸/原型版本与照片、第5课缺失、后续12节教学+第13节展示的配置存储，不作回写变更。

## 工作流：今天不强制做

保留现有两个 Coze Bot 和当前路由，先用 S00/S99 完成一次真实 API 问答核验。若要新工作流，应在非正式学生账号上单独测试路由与回传标记，确定两组基础模型一致、数据连续，再记录真实启用日期。不能说新工作流从第3节就存在。

只新增 W8 表单字段与消息可选元数据，旧路径 `participants/`、`uploads/`、原 `EXPERIMENT_RUN_ID`、原 Blob 命名空间不变。下载ZIP后**不得上传空 data 目录覆盖线上存储**。平台代码不含账号密钥，旧服务器仍需正确配置环境变量。

## 线上开课前确认

1. 备份原代码和数据；上传完整ZIP源码并在原环境构建。
2. 检查 `GET /express/health`（视平台部署路径）应返回 `course-v12.4.8-practice-recorder-optin`。
3. 在教师后台打开当前课次 W8，确认S00、S99均可登录。
4. 两台平板跨设备测试：S00发布后S99看得到，反过来亦然；两者都能保存四项修改记录。
5. 使用正式两个Bot各提问一次，确认有真正AI回复、无研究标签泄漏、管理员导出仍可打开。
6. 未通过任一验证不得直接让全班使用，回滚代码但保留全部线上数据。

## 这次新增加的两件事

1. W8 的求助练习不再出现“相信AI/删掉问题”这种极易排除的选项。三个选择更接近真实决策，学生还要简短说明选择理由；同样改进了 W9/W10 同类练习。
2. 学生页面右上角有“可选录屏”，但**不默认录制**。只有取得相关知情授权后才使用：设备应以 HTTPS 打开平台，勾选授权提示并主动点击“开始录屏”，选择当前平台标签页；结束点击“停止录屏”，再点“保存录像”。视频只在本设备下载，**不会出现在教师后台的现有数据导出中**。

如果是学校 iPad 或使用 HTTP 地址，网页录屏可能不可用；可在学校批准的情况下改用设备原生录屏。请在真实课堂设备上先测试约30秒，确认视频能正常回放。

其他功能（W8最终至少3轮有效AI问答，两组相同；原有学生数据与Blob路径不变）保持不变。
