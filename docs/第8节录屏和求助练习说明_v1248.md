# v12.4.8：第8节录屏及求助小练习改进

## 求助小练习
- 原本第10节“相信AI/删掉问题”等极易排除的选项已改为三种具有表面合理性的求助策略，由学生判断哪种最能解决真实设计困难。第8—10节同类练习已一起改进。
- B组小练习增加**一句简短选择理由**（至少8字），后端随原练习答案保存；A组原有任务确认不变。题目依旧允许不完美答案进入课堂，不因选错阻止学习。
- 已完成旧版练习的学生不会被迫重新回答；新的文字只对更新后尚未完成练习的学生展示，不追溯修改已产生的问卷和日志。

## 录屏：必须由被授权使用者主动开启
- 仅是**可选的本地标签页录制工具**；不采集麦克风、不自动上传原Blob库、不会改变AI轮次或提交门槛。
- 页面右上角有“可选录屏”。只有学校、监护人及学生在适用范围内已完成研究授权后才能勾选确认并点击“开始录屏”；浏览器会再次要求选择共享内容，请只选择**当前平台标签页**。
- **不支持打开网页后静默自动录屏**，浏览器要求用户动作和授权；非HTTPS站点及不支持屏幕捕获的平板浏览器，录屏不可用。
- 开始后自动持续录制，最多55分钟，手动“停止录屏”后须点击“保存录像”保存到平板下载目录。若意外关闭网页、刷新、崩溃或存储不足，录像可能丢失。
- 录屏仅保存在当前设备，学校应确认用途、保管人、加密保存和删除期限，不得将学生屏幕视频上传公开GitHub、公开资料库或群聊。
- 若平板不支持浏览器录屏，可在学校批准且系统允许的情况下使用**平板系统自带屏幕录制**，并由教师按同一编号和日期管理。
- **课前必须用至少一台实际课堂平板验证**：浏览器 HTTPS、标签页共享、停止后下载和回放、50分钟容量与设备空间。

## 原有功能
- W8任务一仍可直接发布；W8最终累计至少3轮有效AI问答，A/B两组相同；不改变W7或其他课次。
- 旧Blob存储名空间、API、学生S编号、原始消息与作品导出路径不变。
- 本地代码测试不代表真实学校设备/线上服务器已联调。
