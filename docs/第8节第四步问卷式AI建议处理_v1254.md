# 第8节第四步：问卷式AI建议处理（v12.5.4）

## 学生端操作
课堂流程不变：①上传图纸和作品图，按需迭代；②填写五步设计过程并发布；③同伴互评；④AI建议处理小问卷。

第四步保留“查看本节完整对话”，可回看本节每条学生消息和AI回复。下面将AI回复的编号条目或文字片段呈现为单选题，每页最多显示3道，包含“已答 X / Y”进度、上一页/下一页按钮。每题六个选项：

1. 已采纳并尝试
2. 调整后采纳
3. 未采纳
4. 准备尝试
5. 还没有决定
6. 仅解释或澄清，无需处理

学生必须按实际情况逐题选择，不必写长篇理由；选择立即记录至现有 `record.text_fields.l08_ai_suggestion_reviews_json`，保留AI消息编号 `message_id`、片段序号 `part_index`、原文 `excerpt` 和决策 `decision`，供教师导出 `ai_suggestion_decisions.csv`。没有完成全部题目时仍然可以“保存进度并退出”，不允许在学生端完成最后一步提交。原本的 `l08_ai_review_complete` 仍用于服务端检验，但由学生端自动设置，不再额外展示重复的确认选择题。

**重要方法边界**：系统按AI原文编号/换行或标点切分为“候选片段”，不是可靠的语义建议识别；纯解释或澄清应选“无需处理”。如果回复包含多个建议但没有明显的分段，原文仍可从对话查看；研究者分析时要人工核对候选片段是否真属于建议。学生选择“已采纳”是自我报告，不能直接等同于已经完成实物修改。未收集或未完成的问卷不能算作未采纳。
