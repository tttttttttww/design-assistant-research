# v12.4.9 第8节学生端精简界面（候选版）

本版继承 v12.4.8 的全部功能，只调整学生端第8节的信息呈现方式，避免屏幕同时堆积大量说明。

## 学生真正需要做的事

1. 进入本节前完成一项小练习（如果平台要求）。提示示例按需展开；对照组原有确认内容不变。
2. 任务一：用简短语句填写设计思维五步与收获，上传一张真实整体原型照片，点击发布作品。此时不强制AI对话。
3. 任务二：查看匿名作品墙，给其他同学的作品提出具体意见；与AI累计完成至少3轮成功问答；记录同学建议的处理决定。
4. 如有修改或参考AI建议，可展开“记录作品修改与AI建议”填写；请按真实情况，不制造修改。下课前的回顾在任务二下方。
5. 点击“完成本节提交”。未完成可先“保存并退出”。

## 精简范围

- 不在每个任务重复解释完整AI计数规则：只在任务二显示进度。
- 五步设计记录改为紧凑排版，保留原字段和必填规则。
- 作品墙默认显示作品照片和互评表；每次仅显示3份同学作品，可切换上一批/下一批；同学详细五步简介和收到的建议按需展开。
- 求助提示、例子默认折叠，可以随时打开；Coze的A/B回复方式未变。
- 教师后台与其他课次的研究过程不删减；不改提交接口、数据存储、学生编号、历史记录和AI路由。

## 部署核验

请备份旧版本和数据，解压源码更新仓库（不要直接把zip作为单一文件上传）。更新后教师后台“检查服务器版本”应显示 course-v12.4.9-student-minimal，随后用S00/S99测试第8节小练习、两组聊天、作品照片上传、作品墙互评、修改记录、3轮提交门槛及历史导出。未通过则恢复原部署并保留数据。

录屏是获学校授权后由学生主动启动、只在设备本地保存的可选功能；不自动上传、不强制提交。
