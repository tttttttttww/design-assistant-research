# 下午第8节操作说明（v12.5.0）

### 学生只要按顺序完成

1. 上传图纸和作品图。如果要修改，点击“继续迭代”上传下一版；不需修改就点击“提交当前版本”；没做完点“保存进度并退出”。
2. 提交后填写设计思维五步的实际过程，点击“上传并发布到作品墙”。
3. 给同学作品写评价，然后完成本课提交。

右侧 AI 在三个步骤都能使用；A、B组仍然是原先不同的人设。本节最终提交至少3轮完整AI问答；上传、迭代和发布不强制凑轮次。

### 教师上线前

- 先备份现有部署和原始数据库/Blob 凭据配置。
- 解压 ZIP 后，按现有 GitHub 仓库目录上传源码（不能只上传 ZIP 文件）。
- 不修改旧环境变量、旧接口、`EXPERIMENT_RUN_ID`。
- 教师后台将当前课次设为 W8，先使用 S00、S99 联调图片、V2迭代、作品墙和3轮对话提交。
- 检查服务器版本号 `course-v12.5.0-flexible-iteration`、真实平板显示和数据导出。
- 如测试异常，停止使用新版并恢复已备份的稳定版本。

### 录屏

可选录屏须获学校授权、浏览器使用HTTPS和用户主动点击授权；视频只保存在本设备，不自动上传服务器。
