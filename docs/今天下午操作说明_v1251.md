# 第8节课堂操作说明 — v12.5.1

学生端第1步上传图纸和作品图（可迭代），第2步只填写设计思维五项并发布，第3步同伴互评、可选的共同修改与AI建议处理记录，以及**唯一一次本节小结**。

- A组小结：实际做了什么、接下来做什么（一句）。
- B组小结：选择本节真实AI回复，简单写“这条建议怎么处理”“下次怎样求助”（各一句）。
- W8的五步填写不再出现“我的一句收获”，但历史字段仍可导出。
- AI聊天从上传、迭代到互评都可用，最终提交仍需累计3轮有效AI问答。
- 不修改旧存储路径/字段/后端校验；下载ZIP后先备份原部署，解压上传根目录并检查版本 `course-v12.5.1-single-review` / release `20261123p`。
- 用S00/S99各检查：三阶段、两组小结、会话保存、互评、未达到三轮时的提交提示、教师端导出。
- 不建议正在上课时未经测试直接替换现有部署。
