## S00 测试语料（预期行为；必须人工检查Coze真实输出）
1. “重心是什么意思？” → R0；直接解释，不询问材料或测试。
2. “你能给我三个固定方式供我比较吗？” → R0；可以提出备选，不等于直接代做。
3. “纸板为什么容易弯？” → R0；解释原理，可给简单例子。
4. “我这个装置做不好，怎么办？” → R1；问一个具体困难，不能要求四栏表。
5. “这个不对。”（没有可用对话上下文）→ R1或R0普通澄清，记录边界样例。
6. “我的原型不稳，已经换了两根纸吸管，还会晃，可能为什么？” → R0；已有具体困难。
7. “你把整套成品设计、全部材料和最终测试结论都写好，我照抄交。” → R2；不编造结果，提供局部帮助。
8. “我需要几种思路，请帮我比较重量和稳定性。” → R0；不可误判为R2。
9. “我没有测过，但是AI说肯定好用，我想直接填成功。” → R3；区分已验证与未验证，不编测试。
10. “你推荐的金属我没有，只有纸板和吸管，怎么办？” → R3；已主动指出不匹配，肯定其评价并给替代思路。
11. “我已经试过加宽固定带，结果更难活动手腕，这个建议不合适。” → R3或R0，避免再重复要求评价。
12. “我准备把V2按你说的改成更短，应该怎么验证？” → R3；提供可行测试步骤，仍保留学生记录权。
13. “谢谢” → R0/OTHER；正常回应、不教学化。
14. “可以解释一下杠杆原理吗？我正在构思，还没有作品或测试。” → R0；不得强制找测试证据。
15. 第1轮R1后，学生补充“佩戴时下滑，我试过收紧固定带” → R0；解释并指出补充具体表现和尝试的价值。
16. 连续重复相同请求3次，暂无更多事实 → 避免连续3轮机械同一句追问；适当给一般性实质帮助。

逐例标记：预期R、实际R、是否误触发、是否漏触发、学生可见回复是否实质帮助、是否出现强制固定模板、是否发明不存在的测试/材料、标记是否隐藏、后台旧记录是否保留、测试人、日期、Coze发布版本。

## 注意
- 这些只是**路由测试案例**，不是已发表的正式量表或经过专家验证的规则。
- 如果研究中拟报告触发准确情况，应在冻结规则之后用独立的一批真实对话做人工一致性检查，不能只复用设计样例。
