# 第8节第四步：对话回看与AI建议记录（v12.5.3）

## 学生操作
前三步保持：上传图纸及作品图（按需迭代）→ 填写五步设计过程并发布 → 同伴互评。
第四步“AI建议记录”：展开查看本节完整学生/AI对话；下方按每条AI回复列出候选句子/分条内容，相关的建议选择“已采纳并尝试、调整后采纳、未采纳、准备尝试、还没有决定”；解释或澄清可选“仅解释或澄清，无需处理”，不相关选项可留空。最后确认“已记录相关AI建议的处理方式”，或如实选择“本节没有需要处理的AI建议”，再完成本节小结及提交。
每项选择自动保存到既有 `record.text_fields.l08_ai_suggestion_reviews_json`，带原始 `message_id`、原文片段及学生决策；管理后台新增 `ai_suggestion_decisions.csv` 方便汇总分析。自动句子切分只是界面提示，不是系统认定每一句均为建议；同一条AI回复若包含多个建议，可以分别选择。
没有选择不等于未采纳，选择采纳也不等于完成实际作品修改。
A/B两组统一表格；原有小结与3轮AI门槛保持。

## 重要边界
- 浏览器端不能无授权录屏，之前可选录屏保持原功能；不增加原始草稿内容采集。
- 不改变云端Blob路径、原始聊天、作品版本及登录分组；旧版历史记录保留。新字段只对升级后实际填写的记录生效。
- 上传前先备份并用S00/S99测试第四步保存与教师端导出，特别注意浏览器旧缓存。
- 若智能体回复极长，自动候选分句最多截取前12项；完整原文依然在回看区和原始数据文件中，未纳入的建议不代表不存在。
