## 当前正式研究结构
- W2：全体普通AI，自主使用，形成自然行为基线。

- W4–W9：正式干预。W4先统一完成“理解使用者需要—明确设计要求与本版重点—纸质V1原型图”，不制作；W5七项制作前审查并上传A4制作准备图（不制作）；W6制作V1；W7测试V1；W8改进V2；W9再测试与总结。实验组 = 普通AI能力 + IHS/EHS/OTHER内部分类路由 + EHS条件性支架；对照组 = 普通AI。

## v11.46核心数据边界
实验组每轮支持型AI会输出隐藏机器标记，服务器剥离后再显示给学生，同时记录：
`agent_route / scaffold_triggered / scaffold_type / route_parse_status / route_protocol_version`。
这些是干预执行记录，不是论文正式编码。正式 IHS/EHS/Other 必须按冻结后的codebook由人工重新编码。

平台同时记录AI输入草稿的开始、编辑/清空、未发送离开、最终发送等事件元数据，但默认绝不保存未发送草稿正文。删除/离开未发送只视为“潜在未发送求助事件”，不能自动等同AHS。
