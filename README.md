## 部署

根目录必须直接包含 `package.json`、`edgeone.json`、`server.js`、`cloud-functions/`、`src/`、`public/`、`scripts/`。
在腾讯云 EdgeOne Pages 使用Node.js 20，安装命令 `npm install`，构建命令 `npm run build`，输出目录 `public`。部署前确认环境变量沿用现有项目设置，不新建数据库或更改 Blob namespace。

本版修复了v11.59构建检查引用不存在教师文件的错误（检查改为实际包含的 `LESSONS_6_TO_13_TEACHER_GUIDE.md`）。
