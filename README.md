## W2 明日任务
W2改编自 TeachEngineering 面向6–8年级、45分钟活动 `Incoming Asteroid! What's the Problem?`。

平台已把本节需要的背景信息直接放在任务页“任务资料包”中，不要求学生另外上网：
- 直径约1英里的小行星、未知撞击点、10天设计期限；
- 撞击后可能出现持续一年或更久的全球性寒冷期；
- Alabraska约1000万人，需要地下避难并携带必要物资；
- 后续选址需要关注的地图信息：海拔、城市与交通、水系、断层、岩石类型、比例尺；
- 海拔、断层线、地质图、比例尺的简明解释；
- 明确提示哪些关键数据是原任务有意不直接提供、需要学生识别为“还需要知道的信息”。

本节任务共6个问题，重点是理解问题、识别约束、比较“一个大洞穴/多个洞穴”的取舍、识别缺失信息并形成问题定义。今天不要求画最终洞穴方案。
