# 设计思维工作坊平台 v12.3.1（求助学习＋五步翻页版）

**部署时间：2026-11-09。** 第6—10节对应 W6—W10，每节60分钟；第11—12节迁移，第13节面向全校师生展示。

## 第0步｜先学习怎样向AI求助

第6—10节，**尚未开始该节任务的支架组学生**会先看到独立的求助学习页：

- **什么时候求助**：自己检查发现了问题，或暂时没验证过某个重要地方。
- **怎样提问**：说明已经做到了哪里、观察到的现象和已尝试的方法。
- **怎样判断AI建议**：学生自己决定采用、修改后采用或暂不采用。
- 每节有一组不合适／更好的提问示例、1道与本课有关的简短情境题，完成后进入五步任务。

普通AI组只进行简短的课堂任务准备；不出现求助策略卡片。学生端不会显示实验分组、研究术语。

**新课次分组：A＝普通AI（对照），B＝带求助支架。** 旧W4/W5采用过去的执行规则，历史数据的 `ai_variant` 不被重新标注。已开始过W6–W10的学生继续使用当时实际记录的AI版本，不能把新加入的课前练习追认为已经完成。

教师测试号：**S00预览支架组、S99预览普通AI组**。新版第0步允许测试号再次预览，不会补写正式学生数据。


## v12.3.1 两组差异与学生端精简

- 第6—10节：**A组是普通AI对照组，B组是求助支架组**，不改变实际已存聊天使用过的AI版本，也不重写旧学生分组。
- 两组保留相同设计任务、必要的作品自检、同伴反馈、AI互动门槛和作品提交要求；**只有B组**看到求助方法第0步、任务中的求助示例提示以及针对AI建议的课末评价与反思。A组只做常规任务准备、使用普通AI并记录中性的任务进度。
- 将“我实际看到了什么？”改成“**我发现了什么问题？**”；如果没有发现问题，可如实记录仍未检查或验证的方面，不要求编造困难。
- 第6节任务一的学习单与标注设计图改为两张紧凑的成果卡，每项一个文件选择框；已保存的图片显示小预览，历史照片折叠查看。完整字段ID和后端上传数据路径不变。

## v12.3.1 上传界面简化

- 第6节任务一仍需分别上传**科学知识与材料学习单**、**标注后的新版设计图**，这是两类不同证据；各选一次照片即可自动保存。
- 设计图和原型的版本管理取消多余的「上传设计图／上传新版本」展开按钮，只保留一处直接可见的文件选择框。学生先简短记录本版变化、主要参考来源和AI建议采纳方式，然后选图自动上传。
- 已保存两个或以上版本时仍保留「上一版／下一版」浏览；只有真实修改才继续上传下一版。历史图片、版本号、时间戳及原有上传API、Blob存储路径均不改变。
- 实际佩戴图、制作进度图继续分开上传，避免将不同证据混为一个文件。

## 每节五步

1. 查看已有成果；
2. 自检、同伴复核，写下真实情况；
3. 用AI分析问题，完成任务一（第6节要用科学知识完善图纸）；
4. 制作、测试或修改原型，保存真实照片；
5. 回顾本节对话和处理决定，保存或提交。

第6节 10＋5轮，第7—10节每节 4＋3轮；只按完整学生—AI问答配对计数。不强迫虚构问题和修改。所有课次可保存进度，上传历史与版本记录不删除。

## 分组与历史记录注意事项

- **平台不会自动改变S01—S30的已存A/B标签。** S04/S05过去被固定在B对照组；v12.3.1取消自动强制改组，请在教师后台核对他们及其他学生真实的分组后，再启动新课次。
- **对于已开始的W6—W10会话，继续按记录中的AI版本运行**；不静默换Coze机器人、迁移或改名学生数据。
- 已经开始过本节任务的正式学生不会被追溯锁在新增第0步之后，以免把尚未实施的干预误记为已实施。
- 仅教师测试号可预览新版第0步。是否看到学习页不能仅凭测试号旧记录判断正式干预实际发生；请查看 `orientation_started` 和 `orientation_completed` 记录。

## 腾讯云 EdgeOne 部署

解压ZIP后，将**压缩包内项目内容**上传仓库根目录（不要上传整个ZIP文件）；根目录包括 `package.json`、`edgeone.json`、`server.js`、`src/`、`public/`、`cloud-functions/`、`scripts/`。
Node.js 20+；安装命令 `npm install`；构建命令 `npm run build`；静态目录 `public`。保留原来的腾讯云Blob实例和环境变量，不能为测试而新建数据存储路径。

发布前用教师后台导出原始数据，部署成功后用S00打开W6：先出现“第0步｜先学会怎样向AI求助”，完成题目再进入五步任务；用S99核对普通任务准备页。还应测试AI发送、图片上传、轮次数和数据导出。
