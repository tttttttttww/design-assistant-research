# 设计思维工作坊研究平台 v11.9

## v11.9 关键更新

- 学生继续使用 **学生编号 + 姓名** 双重核对登录，避免误进他人记录。
- 教师后台新增 **Excel / CSV 名单上传**：支持 `.xlsx`、`.csv`，至少包含“学生编号/编号”和“姓名”两列；“年级”“condition/组别”可选。
- 上传后先显示 30 人预览并检查：编号格式、重复编号、缺失编号、空姓名、年级格式、condition 格式；确认无误后才正式导入。
- 若名单中存在同名学生，后台会明确提示。编号+姓名仍可使用，但同名学生之间误输彼此编号无法靠姓名进一步区分。
- 名单原文件只在服务器内存中解析，**不会保存上传的 Excel/CSV**。确认导入后仅保存“编号 + 姓名”的单向 SHA-256 哈希；姓名明文不进入正式研究数据、不发送给 AI。
- 仍保留“手动批量粘贴名单 / 分组”作为备用方式。
- 首页“进入教师后台”与学生入口同宽同高；任务页保留“换学生 / 退出”。
- v11.7 的表单/聊天状态修复、v11.6 的管理员完整记录与两类 ZIP 导出继续保留。

## 名单文件推荐格式

Excel 或 CSV 第一行推荐使用：

`学生编号 | 姓名 | 年级 | condition`

例如：

`S01 | 张三 | 6 | unassigned`

其中：
- 学生编号必须为 S01–S30；
- 年级接受 6/7/8、六/七/八、六年级/七年级/八年级；
- condition 可留空，也可填写 A / B / unassigned；留空时不会覆盖后台现有 condition；
- 如果文件没有表头，也可直接按“编号、姓名、年级、condition”四列排列。

## 正式数据导出

日常研究主要下载两份：
1. AI聊天 + 聊天图片 ZIP
2. 任务记录 + 学生作品 ZIP

另保留完整正式数据 JSON 作为结构化备份。正式导出自动排除 S00。
