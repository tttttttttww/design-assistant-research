# 设计思维工作坊研究平台 v11.57（干净部署包）

版本日期：2026-11-08

本包以 v11.56 合并保护版为基础，包含 v11.57 的 W8 两阶段任务流程及设计/原型版本迭代功能。ZIP 顶层即项目根目录，`package.json` 位于顶层。

## 本版本课堂流程

- 平台课次 ID 仍为 `W8`，日期为 2026-11-09；学生端显示第六节课。保留既有课次 ID 和历史键。
- 任务一：上传上一课任务单/设计记录；学习教师提供的科学知识；至少选择一个知识点说明其应用位置和作用；选择材料并说明用途；上传标注学习单和完善后的设计图。
- 任务一提交需满足 10 轮完整学生—AI问答及必需材料；提交后开放任务二。
- 任务二：记录并上传 V1 原型/制作进度；后续可追加 V2、V3 等版本。每次新设计版本填写修改记录；纯制作进度照片单独归档。
- 任务二提交需满足 5 轮完整学生—AI问答及必需材料。
- 10/5 轮按当前课次、当前任务阶段中同一 `interaction_id` 的学生消息和 AI 回复配对统计；历史课次、单独AI回复、失败或未配对消息不计入。轮次是课堂提交门槛，不是有效学业求助质量指标。
- 两个任务均允许保存后退出；W9/W10继续保留版本迭代记录，不覆盖旧版本。

## 安装与运行

要求 Node.js 20 或更高版本。

```bash
npm install
cp .env.example .env
# 在 .env 中填写真实环境配置
npm run check
npm test
npm start
```

不要把 `.env`、Coze Token、管理员密码或学生数据放进 ZIP、Git 仓库或公开分享链接。

## 生产部署前必须核对

1. 先备份当前线上部署包，并从管理端下载至少一名已有数据学生的一课原始记录和图片索引。
2. 使用线上当前环境中的原有 `BLOB_STORE_NAME` 与 `EXPERIMENT_RUN_ID`。**不得使用示例值覆盖线上现有值，不得新建替代 Blob 或实验运行 ID。**
3. 确认生产存储模式仍为 EdgeOne Blob，且线上原有对象根路径仍为 `runs/<EXPERIMENT_RUN_ID>/course-v11-enhanced/`。
4. 核对 Coze A/B Bot ID、Token、模型及实际发布的提示词版本；本 ZIP 不会自动修改 Coze 控制台中的 Bot 配置。
5. 先用教师测试号和学生测试号验证登录、W8任务一、10轮门槛、任务一提交、任务二解锁、5轮门槛、版本追加、图片读取、教师导出和W9承接，再开放全班。
6. 历史审计曾指出学生会话身份及图片读取鉴权风险。本包不包含该独立鉴权修复；部署前需确认线上当前分支是否已经合并并通过相应安全测试。
7. 第五节课无可用平台AI对话记录应继续标记为缺失，不回填、不虚构。
