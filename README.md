# 设计思维 + GenAI学业求助研究平台 v11.45

## 当前正式研究结构
- W2：全体普通AI，自主使用，形成自然行为基线。
- W3：共同任务准备，仍是普通AI，不属于正式干预。
- W4–W9：正式干预。W4先统一完成“理解使用者需要—明确设计要求与本版重点—纸质V1原型图”，不制作；W5制作V1；W6测试V1并形成V2计划；W7完成V2关键改进；W8再测试；W9最终修订。实验组 = 普通AI能力 + IHS/EHS/OTHER内部分类路由 + EHS条件性支架；对照组 = 普通AI。
- W7：实验组平台内个人真实query回看；优先选择一条系统EHS候选和一条IHS候选，但学生不看到分类标签。
- W10–W11：两组均普通AI，支架撤除，考察保持/近迁移。
- 问卷候选模块默认关闭，待导师确认。

## v11.45核心数据边界
实验组每轮支持型AI会输出隐藏机器标记，服务器剥离后再显示给学生，同时记录：
`agent_route / scaffold_triggered / scaffold_type / route_parse_status / route_protocol_version`。
这些是干预执行记录，不是论文正式编码。正式 IHS/EHS/Other 必须按冻结后的codebook由人工重新编码。

平台同时记录AI输入草稿的开始、编辑/清空、未发送离开、最终发送等事件元数据，但默认绝不保存未发送草稿正文。删除/离开未发送只视为“潜在未发送求助事件”，不能自动等同AHS。

## 部署
1. `npm install`
2. 配置 `.env`（两个Coze Bot ID、token、存储等）
3. 按本次聊天中确认的两份智能体提示词，分别更新两个 Coze Bot（ZIP 内不再放人设文档，避免混用旧版）。
4. `npm run check`
5. `npm test`
6. 部署。

部署前先用 S00/S99 按 `AGENT_TEST_CASES.md` 做完整测试。

## W4特别说明
- W3历史记录不会被W4覆盖；管理员切换到W4时自动创建/复用W1/W2/W3安全快照。
- 已完成W3的学生可查看并参考旧记录；未完成W3的学生可直接从W4补齐使用者需要与设计要求，并绘制纸质V1原型图。
- 从W4开始，两组AI获得完全相同的最小公共任务上下文与全班公开材料范围，但不会自动获得学生个人方案、困难、实际选材或测试结果。
