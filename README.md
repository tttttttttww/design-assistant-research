# 设计思维工作坊平台 v12.1（简洁翻页版）

**本版适用于：** 第6—10节（W6—W10）每节60分钟，第11—12节迁移任务，第13节面向全校师生上台展示。

## 学生端（每次只显示一页）

进入课次时，先完成简短的课堂准备活动。需要求助指导的学生会看到一条求助策略和一个简短情境；其他学生完成普通任务准备。学生页面不显示研究分组名称。

随后按五步依次完成：

1. **看已有成果**：查看上一节保存的作品；第6节上传上一节纸质学习单（如尚未上传）。
2. **检查设计**：3项简单自检，写下真实观察、同伴意见及当前最想确认的事。选项是“检查过没发现问题 / 发现问题 / 未检查 / 还没做到这一步”，不强迫编造缺陷。
3. **AI讨论与任务一**：先带着真实检查信息向AI提问。第6节把科学知识用进设计图并上传学习单和修订图纸；第7—10节围绕检查结果与AI交流。
4. **做今天的新任务**：制作、测试、优化和保存真实照片，正式原型要有整体图及佩戴图；只记录进度时不要求虚构版本。
5. **回顾并提交**：求助指导条件回顾本节真实AI回答，其他条件填写学习进度。没做完可以保存，不强制提交。

AI始终能在右侧使用；完成一页可保存并翻到下一页，历史聊天和图片不被覆盖。

## 课程及AI对话要求

| 真实课次 | 内部编号 | 主要学习任务 | 阶段AI轮次 |
|---|---|---|---|
| 第6节 | W6 | 科学知识应用、完善图纸、开始原型制作 | 10 + 5 |
| 第7节 | W7 | 继续制作与基础功能检查 | 4 + 3 |
| 第8节 | W8 | 实际测试与同伴反馈 | 4 + 3 |
| 第9节 | W9 | 统一新增条件下的优化 | 4 + 3 |
| 第10节 | W10 | 最终证据整理和作品说明 | 4 + 3 |
| 第11节 | W11 | 全校舞台讲解设计 | 普通AI |
| 第12节 | W12 | 试讲与改进 | 普通AI |
| 第13节 | W13 | 全校正式舞台展示 | 不提供AI |

轮次按学生提问及AI真实回复配对统计，不代表求助质量。

## 腾讯云 EdgeOne 部署

ZIP解压后的**目录内容**直接是项目根目录，必须有 `package.json`、`edgeone.json`、`server.js`、`public`、`src`、`scripts` 和 `cloud-functions`。

Node.js 20；安装命令 `npm install`；构建命令 `npm run build`；输出目录 `public`。**不要重建原有数据存储或修改现有环境变量。**

v12.1沿用原来的 Blob 存储路径和会话ID。已保存的文本、图片、对话保持原路径，新增界面只是改变呈现和分步操作。若v12启用前已经使用了W6—W10，部署前应在原后台导出备份，并核对历史数据是否对应新课次。
