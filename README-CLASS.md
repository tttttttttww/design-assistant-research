# 设计思维工作坊：11月16日第7节课堂版

## 部署与开课（教师阅读）

此 ZIP 是完整的项目源代码：`public/` 是学生与教师网页，`cloud-functions/` + `src/` 是后端，`scripts/` 供构建验证，`.env.example` 仅是变量名称示例。

1. **先备份**：如果有可访问的原正式数据，先从教师端导出；不要修改 `EXPERIMENT_RUN_ID`、`BLOB_STORE_NAME` 或现有 Blob 存储实例/路径。
2. 将解压后的**全部文件**（不是外层文件夹、不是 ZIP 本体）上传到 GitHub 项目根目录；原项目中不再使用的旧 `public/*.html` 和旧 `public/js/*.js` 应单独核对后删除，否则旧网页可能仍能从旧链接访问。
3. EdgeOne Pages 需要从 GitHub `main` 触发**新一次成功构建**，不是继续使用旧预览链接。项目应启用 Node.js 云函数、EdgeOne Blob 存储，并配置 `BLOB_STORE_NAME`、`ADMIN_PASSWORD`、`COZE_ACCESS_TOKEN` 及两只 Bot 的 ID。所有密钥只在腾讯云环境变量中配置，不应上传到 GitHub。
4. 在新的预览链接打开 `/admin.html`，页面显示「网页版本 2026-11-16 课堂版」，登录后点击「检查服务器版本」，应看到 `20261116d`；服务器检查失败时，**先修云函数/Blob/环境变量**，不要让学生集体使用。
5. 教师端选择 **W7（实际第7节）**，确认「向学生开放当前课次」已勾选、没有锁定，然后保存。S00 测试上传图纸、进入原型、再次修改图纸、上传整体图和佩戴图、10轮有效问答、最终提交以及教师端查看记录/导出。两种AI条件还需要分别核对。

## 第7节学生任务

- 第0步：A组正常任务确认；B组按既有求助策略学习与练习进入（不向学生显示组别）。
- 第1步：查看上一节真实记录/纸质图纸；第2步：完成3项检查并记录发现或尚未验证的问题（同伴意见可选）。
- 第3步：设计图有需要就追加修改版；已有图纸满意可直接进入制作。已经进入原型后仍可回到图纸阶段追加真实修改版，不限制版本次数。
- 第4步：实体原型可以反复修改；每版正式原型上传整体图 + 实际佩戴图。尚未做完可上传过程照片并「保存进度并退出」。
- 第5步：本节图纸与原型两个阶段**合计至少10轮完整学生发问+AI回复**，才允许最终提交。B组真实对话回顾、A组中性进度记录保持区分，不因要求10轮而取消干预。

## 必须明确的限制

- ZIP 更新**不会自动迁移第三方旧服务器中的学生数据**；之前记录若未在当前 Blob，页面不能凭空显示旧图或聊天，也不应当作学生没做过。
- 如果 EdgeOne Pages 只部署静态网页，没有运行云函数/Blob，页面看起来正常也无法稳定保存学生状态。这是部署配置问题，不是更换ZIP就能自动解决。
- 正式学生 S01—S30 的研究记录禁止批量重置；S00、S99 用于测试。数据实际保存位置及环境配置须先验收。
